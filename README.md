# Лабораторная работа 1.7

## Электронный каталог книг

### Цель работы
Реализовать сохранение и загрузку данных электронного каталога книг в XML-файл, добавить меню управления файлами и запоминание последнего открытого каталога.

### Реализованные функции
- **Сохранение каталога:** запись списка книг и сведений об авторах в XML.
- **Загрузка каталога:** чтение данных из XML-файла.
- **Создание нового каталога:** очистка текущего списка для начала работы с новым каталогом.
- **Открытие файла:** выбор XML-файла через `FileChooser`.
- **Сохранение и сохранение как:** запись данных в текущий или выбранный файл.
- **Запоминание последнего файла:** хранение пути к каталогу с помощью `Preferences`.
- **Меню приложения:** команды создания, открытия, сохранения и выхода.
- **Обработка ошибок:** вывод сообщения, если файл не удаётся прочитать или сохранить.

### Используемые технологии
- Java
- JavaFX
- FXML
- XML
- DOM API
- `FileChooser`
- `Preferences`
- Maven

### Основные классы
- `Launcher.java` — запуск приложения, меню и управление файлами.
- `BookXmlStorage.java` — чтение и запись данных каталога в XML.
- `Book.java` — модель книги.
- `Author.java` — модель автора.

### Результат
Приложение позволяет сохранять каталог книг в XML, открывать ранее сохранённые каталоги и восстанавливать последний использованный файл при следующем запуске.

### Запуск проекта
Открой проект в IntelliJ IDEA и запусти класс `Launcher.java` либо используй конфигурацию запуска Maven/JavaFX, настроенную в проекте.
